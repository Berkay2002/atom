# atom — web demo

Browser port of the `atom` hydrogen-orbital visualizer. The Rust math from
`crates/atom-core` is compiled to WebAssembly; the volume is baked off-thread
in a Web Worker; the renderer is raw WebGL2.

This slice is the tracer bullet: it draws a fixed `(n=1, l=0, m=0)` orbital
from a hardcoded camera with a grayscale colormap. Interaction, controls,
presets, and persistence land in later slices.

## Local development

Requires Rust toolchain, `wasm-pack`, and Node 18.17+.

```powershell
cd web
npm install         # one-time
npm run dev         # builds wasm + starts next dev on :3000
```

The `predev` script rebuilds `atom_core.wasm` into `web/wasm/` before
each `next dev` start. If you change Rust sources mid-session, restart
`npm run dev` (or run `npm run wasm` manually) to rebuild the WASM.

`npm run build` does the same for production output.

## Deploying to Vercel

The Vercel project root must be `web/`. From the repo root:

```bash
cd web
vercel login          # one-time
vercel link           # one-time — pick / create the project, point root at web/
vercel --prod         # deploy
```

`vercel.json` sets `buildCommand` to `bash ./scripts/build-wasm.sh && next build`,
so Vercel's Linux build environment compiles `atom-core` to WASM before
`next build` runs. `scripts/build-wasm.sh` installs `rustup` and `wasm-pack`
on demand because Vercel's default Node image ships neither.

No special HTTP headers (no COOP/COEP) are required — the WASM is
single-threaded.

## Layout

```
web/
  scripts/build-wasm.{sh,ps1}    # wasm-pack invocation (Linux / Windows)
  src/
    app/                          # next.js app router
    components/AtomCanvas.tsx     # worker + renderer + rAF glue
    lib/
      bake-worker.ts              # off-thread WASM bake
      camera.ts                   # fixed-view math (mirrors desktop camera.rs)
      renderer/
        raymarch.ts               # WebGL2 module
        shaders.ts                # GLSL ES 3.00 vert + frag
  wasm/                           # generated by scripts/build-wasm.* (gitignored)
  vercel.json
```
